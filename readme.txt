== Installation ==
1. Upload the plugin files to `/wp-content/plugins/brikpanel` or install via **Plugins → Add New → Upload**.  
2. Activate through the **Plugins** menu.  

== Frequently Asked Questions ==

= Can I customize the WooCommerce dashboard widgets? =
Yes. You can hide widgets on the Dashboard by using the screen options button in the upper right corner.

= Will it work compatibly with the Admin Menu Editor plugin? =
Yes, it works in full compatibility.

= Is Brikpanel a theme or a plugin? =
Plugin. It works with any theme and page-builder.

= Will it slow down my site? =
Not at all. Brikpanel is lightweight and optimized for speed. It enhances your admin panel experience without affecting your front-end store performance. Your WooCommerce shop stays fast, while your dashboard becomes even faster.
